# 城市队列批量购买1.0.0（电脑客户端补丁）

适配已校验的Unciv 4.22.6-patch1 Windows版，要求游戏附带Java21。不是普通JSON模组，原版Android不能安装此补丁。

安装包解压到游戏根目录后，补丁位于extensions/BulkPurchase。使用游戏目录的“启动批量购买.cmd”启动；普通Unciv.exe入口不加载此补丁。先在游戏中保存并自行退出，再运行新启动器。启动器只在你主动运行时启动游戏；不改原游戏JAR，不改存档。

进入自己城市，先把要购买的建筑/单位加入生产队列，再点原购买按钮旁的“购买队列”，确认后按队列顺序购买。结果弹窗列出实际花费和每项结果。

所有价格、折扣、科技、战略资源、驻军/飞机载位、傀儡/抵抗状态均采用原版购买校验。只使用金币；不使用信仰，不绕过奇观禁购，不在神模式伪装正常付费。金币不足或不满足条件的项目跳过并保留；原版队列校验可能移除本来就不可建的项目。购买后游戏自动补入的新项目不在此次批量范围内。

同类单位连续购买会受到城市格占用限制，需要先把前一单位移走，再购买后续单位。补丁不通过瞬移或免费移动绕过该规则。

卸载：使用原来的Unciv.exe启动即可不加载。保留extensions目录也不会自动运行；购买所得建筑和单位仍按原版存档保存。

移植到其他电脑：把本目录复制至游戏extensions/BulkPurchase，运行start.ps1 -GameDirectory 游戏目录。版本或哈希不符会拒绝启动。
